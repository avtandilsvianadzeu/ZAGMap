About ZAG Digital Atlas

A GIS atlas showing where the Slovenian National Building and Civil Engineering Institute (ZAG) has documented involvement: buildings, bridges, tunnels, dams, cableways and research sites, with the type of work and the source for each record.

It is a digital atlas, not a national BIM database. BIM/IFC information can be linked later where it is publicly available.

How records are classified

  • Documented: at least one published source describes ZAG's work (blue marker).
  • Referenced: a named partner or a site mentioned in sources without a described ZAG role (grey marker).
  • ZAG facility: ZAG's own premises (dark marker), kept separate from projects.
  • Involvement types follow the published description of each record.
  • Bridges, tunnels and cableways are matched at runtime to the structure in OpenStreetMap and drawn as their real alignment; buildings to their footprint. Where no match is found, the recorded position is shown with its precision and a shaded circle.

Data sources

  • ZAG publications and the sources cited on each record.
  • OpenStreetMap contributors via OpenFreeMap (map and building footprints), Photon geocoder.
  • Terrain: Mapzen / AWS Terrain Tiles. Satellite: Esri World Imagery. Optional orthophoto: GURS DOF025 via Level2.si (CC BY).
  • Building attributes: GURS Kataster nepremičnin (OGC API Features, CC BY 4.0), queried for the selected building.
