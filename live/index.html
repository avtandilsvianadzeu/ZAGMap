ZAG Digital Atlas

Geographic atlas of buildings, bridges, tunnels, dams, cableways and research sites in Slovenia where the Slovenian National Building and Civil Engineering Institute (ZAG) has documented involvement. Each record carries the type of work, a short description, the structure's attributes and the source.

Data sources

  • ZAG publications and the sources cited on each record
  • OpenStreetMap via OpenFreeMap (map, building footprints, structure alignments); Photon geocoder
  • GURS Kataster nepremičnin, OGC API Features (building attributes); GURS DOF025 orthophoto via Level2.si
  • Terrain: Mapzen / AWS Terrain Tiles; satellite imagery: Esri World Imagery

Coordinate reference system WGS 84 (EPSG:4326), display in Web Mercator (EPSG:3857). Dataset: data/zag_projects.geojson.
